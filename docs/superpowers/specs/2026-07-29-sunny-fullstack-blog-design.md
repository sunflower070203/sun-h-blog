# Sunny 全栈个人博客设计规格

## 1. 产品目标

为东南大学本科生 Sunny 建立一个以科研学习为主、生活记录为辅的个人博客。公开网站延续帆船、海洋、暖白与克制半透明的视觉方向；管理后台以舒适写作为第一目标，不要求通过 GitHub 或 Markdown 发布文章。

## 2. 用户与权限

第一版只有一个管理员账号：

- 访客无需登录，可浏览已发布文章和项目。
- 管理员通过 `/admin/login` 登录。
- 不提供公开注册、多用户协作、评论、点赞或私信。
- 管理会话使用 HttpOnly、Secure、SameSite Cookie。
- 密码只保存 Argon2 哈希。
- 登录接口包含速率限制；管理写操作校验 CSRF。

## 3. 公开网站

### 首页

- 帆船全宽首屏与 Sunny 的身份简介。
- 精选科研项目。
- 最新科研/学习文章。
- 少量生活文章。
- 关于 Sunny 与联系方式。

### 内容页

- 文章列表支持分类、标签和关键词筛选。
- 文章详情包含封面、发布时间、阅读时间、正文和相关标签。
- 项目页展示问题、过程、结果与项目链接。
- 未发布草稿不会出现在公开接口和搜索结果中。

## 4. 管理后台

### 仪表盘

- 显示草稿数、已发布文章数和最近更新。
- 提供“新建文章”主操作入口。

### 文章编辑器

- 标题、摘要、分类、标签、封面、正文、是否置顶。
- 富文本编辑支持标题、段落、列表、引用、链接、代码块和图片。
- 支持保存草稿、预览、发布、撤回发布和删除。
- 自动保存当前编辑内容；离开未保存页面时提醒。
- 文章路径由标题生成，可手动修改且保持唯一。

### 媒体

- 图片上传到兼容 S3 的对象存储。
- 服务端校验文件类型和大小。
- 数据库只保存对象 URL、尺寸和替代文本。

## 5. 技术架构

使用一个代码仓库：

- `apps/web`：React + Vite 公共网站与管理后台。
- `apps/api`：Node.js + Fastify REST API。
- `packages/shared`：前后端共享类型与验证规则。
- PostgreSQL：文章、项目、分类、标签、管理员和媒体元数据。
- S3 兼容对象存储：文章封面与正文图片，兼容火山引擎 TOS。

生产环境由 Nginx 提供同域入口：

- `/api/*` 转发至 API。
- 其他路径返回前端静态资源。
- 同域部署避免额外 CORS 与跨站 Cookie 配置。

## 6. 数据模型

- `admins`：账号、密码哈希、创建与更新时间。
- `posts`：标题、路径、摘要、正文 JSON、状态、分类、封面、置顶、发布时间。
- `posts.tags`：文章标签数组。个人单管理员场景无需额外关联表。
- `projects`：名称、摘要、正文、状态、年份、链接和排序。
- `media`：对象键、URL、类型、尺寸、替代文本。

删除文章不会自动删除媒体对象，避免图片仍被其他内容引用时损坏。

## 7. API 边界

公开接口仅返回已发布内容：

- `GET /api/posts`
- `GET /api/posts/:slug`
- `GET /api/projects`
- `GET /api/tags`

管理接口要求登录：

- `POST /api/auth/login`
- `POST /api/auth/logout`
- `GET /api/admin/posts`
- `POST /api/admin/posts`
- `PUT /api/admin/posts/:id`
- `POST /api/admin/posts/:id/publish`
- `POST /api/admin/posts/:id/unpublish`
- `DELETE /api/admin/posts/:id`
- `POST /api/admin/media`

## 8. 部署与交付

项目提供：

- 完整源代码。
- `docker-compose.yml`，用于本地与火山引擎 ECS。
- PostgreSQL 服务和持久化卷。
- 前端、API、Nginx 的 Dockerfile。
- `.env.example`，不包含真实密码或密钥。
- 数据库迁移和管理员初始化命令。
- 中文 README，包含本地启动、火山引擎部署、TOS 配置、HTTPS 和 GitHub 上传步骤。
- ZIP 压缩包，方便直接上传。

GitHub 只承担源码版本管理，不参与日常发帖流程。

## 9. 验证标准

- 未登录无法访问管理接口。
- 管理员可完成“登录 → 新建草稿 → 上传封面 → 预览 → 发布”。
- 已发布文章能在首页和文章详情页访问。
- 草稿无法通过公开 API 访问。
- 页面在桌面和移动端均可使用。
- 前端、API 和数据库可通过 Docker Compose 启动。
- 所有密钥通过环境变量注入，仓库中不包含真实凭据。

## 10. 明确不做

第一版不包含多管理员、公开注册、评论、点赞、订阅邮件、访问统计、全文搜索引擎、AI 写作和移动客户端。
