# Sunny 博客科研索引与写作后台改造设计

日期：2026-08-10

## 目标

在不更换现有 React、Fastify、PostgreSQL、Docker Compose 架构的前提下，将 Sunny 的个人博客改造成以科研索引为核心、生活记录为辅的单作者博客。公开页面参考 `mratgnothing/mratg-blog` 的内容层级与文章阅读体验，但不复制像素风、文案或素材。后台保留网页发布，并增加 Markdown 与多图片能力。GitHub 仅保存源代码。

## 明确排除

- 不开放访客注册、评论或点赞。
- 不使用 GitHub 提交文章作为日常发布流程。
- 不把 `.env`、数据库、上传图片、备份或密钥提交到 GitHub。
- 不采用参考项目的像素风视觉。
- 不在公开页面应用管理员壁纸。

## 公开网站

### 首页

首页采用“科研索引”布局。桌面端使用窄侧栏或等价的稳定导航区，主体依次展示个人简介、当前研究方向、项目索引、近期文章和次级生活栏目。移动端折叠为顶部导航，保持研究内容优先。

视觉继续使用海洋色、帆船意象、纸张底色和克制的半透明层。信息层级通过编号、细分隔线、标题字重和留白形成，不使用像素素材。

### 文章列表与详情

文章列表支持搜索、分类和标签过滤。文章详情采用稳定阅读宽度，支持封面、标题、摘要、发布时间、更新时间、标签、标题层级、代码块、引用、单图、图片说明和响应式图集。旧文章必须继续正常渲染。

## 管理后台

### 文章管理

仪表盘提供搜索、发布状态筛选、分类筛选、分页和清晰的更新时间。单篇文章支持编辑、复制、发布、撤回和删除。批量操作只包含发布与撤回，删除仍要求逐篇确认，避免误操作。

### 后台壁纸

管理员可上传一张后台壁纸，并设置遮罩强度、模糊度和显示位置，也可恢复默认。壁纸设置保存在服务端，登录后跨设备生效。界面强制保留最低遮罩强度，保证文字对比度；公开网站不读取该设置。

### 双模式编辑器

写作页提供富文本和 Markdown 两种视图。两种视图操作同一份文章内容，不建立两份独立草稿。切换时进行可预期的转换，并对无法无损转换的结构给出提示。支持导入 `.md` 文件、粘贴 Markdown、自动保存、手动保存、预览、草稿、发布和撤回。

Markdown 导入只处理正文内容；标题、摘要、分类、标签、封面、状态等仍由右侧元数据面板管理，避免隐式 front matter 覆盖现有字段。

### 多图片工作流

编辑器支持文件多选和拖放。每张图片独立上传并显示进度、成功 URL 或失败原因；失败项目可单独重试，不回滚已成功图片。

上传完成后可选择：

1. 按选择顺序逐张插入当前光标位置；
2. 生成响应式图集区块。

图集允许排序、删除单图并填写替代文本。桌面端根据图片数量使用两列或三列，移动端自动退化为单列。图片继续写入 Docker `media_data` 卷，不进入 GitHub。

## 数据与接口

现有文章结构保持兼容。只有在后台壁纸或图集结构无法由现有字段表达时才增加最小数据库迁移。站点设置使用单记录配置或等价的键值结构，由管理员认证保护。上传 API 支持多次并发的单文件请求，避免一个大请求失败导致全部图片丢失。

正文以单一规范格式持久化。实现阶段先验证现有 TipTap JSON 与 Markdown 转换的覆盖范围，再确定以 TipTap JSON 还是 Markdown 作为规范源；不得同时把两份正文都作为权威数据。

## 错误处理

- Markdown 导入失败时保留原正文并显示具体原因。
- 模式转换前保留本地恢复快照。
- 图片上传按文件显示结果，失败可重试。
- 保存和发布失败不清除本地草稿。
- 壁纸上传失败不替换当前设置。
- 批量操作返回逐篇结果，不将部分成功显示为全部成功。

## 测试与验收

- 现有登录、草稿、发布、撤回、删除和封面上传测试继续通过。
- 增加 Markdown 导入、模式切换和不支持结构提示测试。
- 增加多图部分失败、顺序插入、图集增删排序和移动端渲染测试。
- 增加壁纸权限、设置持久化、最低遮罩和恢复默认测试。
- 增加文章筛选、复制及批量发布/撤回测试。
- 验证旧文章无需人工迁移即可阅读和编辑。
- 运行类型检查、单元测试、生产构建和 Docker Compose 配置校验。

## GitHub 与部署

目标仓库为 `https://github.com/sunflower070203/sun-h-blog`。推送前检查远端状态和本地忽略规则，确保秘密与运行数据未进入提交。源代码、迁移、测试、README 和部署说明进入仓库。

本地验证完成后才更新腾讯云服务器。部署保留现有 PostgreSQL 数据与 `media_data`，先备份数据库和必要配置，再构建并执行迁移。域名审核期间继续使用现有公网入口；HTTPS 启用后再将安全 Cookie 配置切回安全模式。

## 成功标准

Sunny 可以在 `/admin` 中自定义后台壁纸，高效查找和管理文章，在富文本与 Markdown 间写作，一次导入多张图片并选择逐张插入或图集排版。访客看到的是非像素风、科研优先的索引式首页和稳定的文章阅读排版。现有文章、管理员账户和媒体保持可用，完整源代码安全推送至指定 GitHub 仓库。
