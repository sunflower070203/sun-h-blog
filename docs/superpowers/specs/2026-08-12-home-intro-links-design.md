# 首页简介与外部链接调整

## 目标

减少首页和个人介绍页的重复标题，让个人资料内容保持单一来源，并使外部链接更接近 GitHub Profile 的紧凑列表。

## 页面行为

- 顶部导航继续显示“个人介绍”，并继续进入 `/about`。
- 首页原“个人介绍”标题改为“简介”。
- 首页简介完整渲染后台保存的 `aboutContent`，不截断内容，也不增加第二套 README 数据。
- 后台现有 README.md 导入功能保持不变；导入并保存后，首页简介和 `/about` 共用更新后的内容。
- 首页外部链接位于简介下方，按后台顺序纵向排列。每行显示标题和可选说明，整行可点击，继续使用安全的新标签页属性。
- `/about` 删除顶部 “About” 标签和重复的大号“个人介绍”标题，正文或空状态直接作为页面主体。

## 范围

只修改公共首页、个人介绍页、相关公共样式和回归测试。不修改资料 API、数据库、后台编辑器、导航名称、文章页面或其他服务器服务。

## 验证

- 测试确认首页标题为“简介”，导航仍为“个人介绍”。
- 测试确认 `/about` 不再渲染标题区，但仍渲染正文与空状态。
- 测试确认外部链接保持纵向、安全、按原顺序展示。
- 运行完整测试、类型检查和生产构建，并在部署后检查首页与 `/about`。
