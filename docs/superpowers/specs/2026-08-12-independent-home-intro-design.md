# 独立首页简介与 Profile 链接设计

## 目标

首页使用独立、简短的富文本简介；个人介绍页继续使用现有完整富文本和 README.md 导入。两份内容互不覆盖。外部链接改为 GitHub Profile 左栏式列表，并只使用统一的预设图标。

## 公共页面

首页保持桌面两栏结构：

- 左栏依次显示头像、显示名称、首页简介和外部链接。
- 右栏只显示置顶文章。
- 首页不再把简介和外部链接作为右栏的大型 section。
- 手机端按头像与姓名、简介、外部链接、置顶文章的顺序单列排列。

首页简介完整显示独立字段 `introContent`。它支持段落、粗体、链接和无序列表，不支持 README.md 导入、图片、图集、标题、引用或代码块。建议内容保持在约 600 个纯文本字符以内；共享输入契约负责拒绝超限内容。

`/about` 继续只显示现有 `aboutContent`，保留后台 README.md 导入、多图片和完整编辑工具。现有个人介绍数据不得复制、清空或迁移到首页简介。

## 外部链接

每条链接保留标题、URL 和可选说明，并新增 `icon` 枚举字段。支持以下预设：

- `github`
- `email`
- `website`
- `scholar`
- `orcid`
- `linkedin`
- `link`（通用回退）

公共首页每条链接显示统一尺寸的小图标、标题和可选说明，整行可点击，并继续使用 `target="_blank"` 与 `rel="noopener noreferrer"`。不允许上传自定义图标，不新增图标 URL 字段。现有链接迁移后默认使用 `link`，不会丢失标题、URL、说明或顺序。

## 后台编辑

个人资料页分为三个清晰区域：

1. 基本资料：显示名称、头像。
2. 首页资料：极简富文本“首页简介”和外部链接。每条链接可选择预设图标。
3. 个人介绍：现有完整编辑器、README.md 导入与多图片功能。

保存仍使用同一个管理员资料接口，避免出现两个保存按钮互相覆盖。上传头像和现有个人介绍图片的行为不变。

## 数据与迁移

- `site_settings` 新增非空 JSONB 字段 `intro_content`，默认值为空 TipTap 文档。
- `PublicProfile` 新增 `introContent`。
- `ProfileLink` 新增有默认值的 `icon` 枚举。
- 数据库中的 `links` 仍是原 JSONB 列，不新增图标列；迁移将现有数组内缺失的 `icon` 补为 `link`。
- 迁移只允许增量 `ADD COLUMN IF NOT EXISTS` 和针对链接 JSON 的安全回填，不删除或覆盖 `about_content`。

## 错误处理与兼容

- API 对旧链接数据进行默认值解析，避免迁移窗口内读取失败。
- 非法链接协议继续被拒绝。
- 非法图标类型返回清晰的 400 响应。
- 首页简介加载失败时使用空简介，但外部链接和置顶文章继续显示。
- 图标由前端内置 SVG 渲染，不增加第三方图标依赖。

## 测试与验收

- 契约测试覆盖简介富文本白名单、纯文本长度上限和图标枚举/default。
- 迁移测试确认新增字段安全、现有链接默认图标回填且无破坏性 SQL。
- API 测试覆盖公开投影和管理员保存/读取两份独立内容。
- 后台测试覆盖简介编辑、图标选择、README 仍只导入个人介绍。
- 首页渲染测试确认左栏顺序、预设 SVG、安全链接和右栏仅保留 Pin。
- 完整测试、类型检查、生产构建通过后，再部署并验证真实数据库迁移、后台保存刷新及公共页面。

## 不在本次范围

- 自定义图标上传。
- 首页简介 README.md 导入。
- 新增注册、评论、公开编辑或第二套管理员页面。
- 修改文章内容、个人介绍现有内容、OpenClaw 或竞赛网站。
