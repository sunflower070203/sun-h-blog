# Sunny Blog 聚焦型首页设计

## 目标

保留当前 Fuwari 风格的横幅、悬浮导航、双栏结构和明暗模式，减少首页重复信息。访客在首屏能够识别作者、进入关键外部链接、看到一篇代表作和最近更新。

本阶段只制作本地 Demo，不推送 GitHub，不部署生产环境。

## 首页结构

### 顶部

- 保留后台可配置横幅及图片焦点。
- 保留悬浮导航：首页、科研学习、日常生活、个人介绍、明暗模式。
- 不改变现有导航路由和主题记忆方式。

### 左栏

首页只保留一个作者卡片，内容依次为：

1. 头像。
2. 显示名称。
3. `bio` 纯文本简介，建议不超过 120 个汉字。
4. 最多四项“图标＋名称”外部链接。

首页不再渲染 `introContent`。完整富文本仍由“个人介绍”页面的 `aboutContent` 承载，后台个人资料编辑功能保持不变。

删除首页的独立外部链接卡、分类统计和标签云。超过四项的链接继续保存在后台数据中，只是不进入首页。

### 右栏

- 有置顶文章时，第一篇置顶文章显示为带封面的主卡片。
- 没有置顶文章时，隐藏整个置顶区域，不显示空状态。
- 最近更新显示最多三篇非置顶文章。
- 最近更新使用紧凑文字列表，只显示日期、分类、标题和一行摘要，不加载封面。
- 置顶文章不在最近更新中重复出现。
- “全部文章”继续链接至文章归档页。

### 页脚

主页底部居中显示：

- `晋ICP备2026010770号`，链接至工信部备案系统。
- `苏公网安备32011502014222号`，链接至公安备案查询地址，并使用公安平台要求的图标。

正式部署前需要确认两项备案都属于 `sun-h-blog.cn`。设计不根据属地文字自行修改备案号。

## 响应式布局

- 桌面端维持作者卡和文章内容双栏排列。
- 760px 以下改为单栏，顺序为作者卡、置顶文章、最近更新、备案页脚。
- 移动端外部链接保持图标和名称，点击区域满足触控尺寸。
- 导航继续允许横向滚动，不隐藏主要栏目。

## 数据与性能

- 不增加数据库字段或 API。
- 复用现有 `profile.bio`、`profile.links` 和文章列表数据。
- 首页不再导入 `RichDocument`，避免为了短简介加载 TipTap 富文本渲染依赖。
- 个人介绍页和文章详情页仍可使用现有富文本渲染器。

## 测试与验收

- 首页只显示一段简介，不输出 `introContent`。
- 首页外部链接最多四项，保留原始顺序并显示图标和名称。
- 首页不再出现独立外链卡、分类和标签区。
- 置顶区域在无置顶文章时完全隐藏。
- 置顶文章不会出现在最近更新中；最近更新最多三篇。
- 公共首页不存在管理后台入口。
- 备案号文字和链接正确。
- 在 1280、760 和 390 像素宽度下无横向溢出。
- 明暗模式下文字、链接和卡片对比度正常。
- 完整测试、类型检查和生产构建通过。

## 明确不做

- 不删除后台保存的简介、链接、分类或标签数据。
- 不改变科研学习、日常生活、个人介绍和文章详情页面。
- 不新增搜索、评论、注册或新的内容模型。
- 本地 Demo 通过前不提交功能代码、不推送、不部署。
